# Edit PIM Template

Opens the template with its saved values. The fields are the same as on [Add PIM Role Settings Template](add.md). Saving re-validates the template against the secure floor, keeps the original creator, and records who last updated it and when.

Tenants that have the template deployed through the **PIM Role Settings Template** standard pick up the change on the next standards run and report drift until then.
